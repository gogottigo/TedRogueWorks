# Шрифт сайта — Patch 05

Основной шрифт: Inter Variable, normal, диапазон весов 100–900.
Источник файлов: npm `@fontsource-variable/inter` 5.3.0.
Публичный архив источника и SHA256 выбранных файлов записаны в `FONT_ASSETS.json`.
Лицензия и авторство сохранены в `public/fonts/OFL.txt` (SIL Open Font License 1.1).
Сам шрифт не модифицировался; `TRW Inter` — только имя семейства в CSS сайта.

Включены latin, latin-ext и cyrillic. Latin-ext нужен в том числе для знака рубля.
Три файла занимают 152 072 байта (около 149 КиБ); точные размеры — в JSON. Системный моноширинный шрифт
сохраняется для команд и отдельных служебных меток. При недоступности основного шрифта
остаётся системный fallback.

В разработке файлы обслуживаются локально из public/fonts. При сборке `portable-build.mjs`
встраивает эти три WOFF2 в общий CSS как data URL. Поэтому одна и та же готовая сборка
сохраняет шрифт на HTTP, во вложенном каталоге и при file:// без внешнего шрифтового сервиса
и без отключения браузерных ограничений CORS. Отдельного SPCK-архива нет.

Для обновления шрифта нужно заменить исходные файлы и при необходимости unicode-range,
сохранить актуальную лицензию, затем пересобрать и проверить все три способа запуска.
Сайт не требует установки Fontsource пользователем или загрузки шрифта из сети во время просмотра.
