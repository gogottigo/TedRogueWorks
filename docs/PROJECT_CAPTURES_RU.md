## Пекарня: условия запуска

Из присланного ZIP установлены requirements-dev в отдельный venv, запущены Mini App,
API и main через штатный tests/serve_pv108rc4_browser.py. Транспорт Telegram и платежей
синтетический, SQLite временная. Созданы три демонстрационных заказа нормальными API;
тестовый провайдер подтвердил их оплату; штатными действиями выставлены «Готовим»,
«Готов к выдаче», третий остался «Оплачен». Корзина — два вида выпечки, три единицы.
Настоящие сообщения, клиентские аккаунты и деньги не использованы.

Для текущего RC6 в локальном QA fixture исправлен поиск invoice для тестового подтверждения:
он берётся из payment_attempts.provider_payment_id, а не устаревшего orders.invoice_id.
Это изменение только тестовой среды съёмки, не продукта пекарни; сам fixture и журнал
сценария приложены в docs/capture-support. Нативный внешний вид чата бота здесь не снят.

или прав на весь корпус фотографий в эту задачу не входила.
