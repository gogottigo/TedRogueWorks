# Patch 03 — портфолио и реальные экраны

Основа — полный Patch 02, коммит `8525b41`. Работа выполнена локально;
действующий сайт и удалённый GitHub не изменены.

## Что сделано

- Общая страница проектов и три полноценных кейса на русском и английском.
- В каждом кейсе: задача, роль студии, выполненные работы, путь пользователя,
  результат текущего этапа и честные границы реализации.
- Добавлен разрешённый кейс ПрофСантех+, без заявления о подключённом складе
  или уже опубликованной обратной ссылке.
- Главная и страница проектов используют единые данные трёх кейсов.
  Пекарня теперь представлена как Telegram-бот и Mini App.
- Декоративное превью бота и отдельная промышленная картинка заменены настоящими экранами.
- Запущены все три проекта, сделаны 45 снимков. Отдельный `SCREENS.html`
  позволяет открыть любой размер, включая варианты вне выбранных галерей сайта.
- Галереи: увеличение, подписи с размером, предыдущий/следующий экран,
  клавиши ←/→, Escape, закрытие и возврат фокуса. Без JavaScript снимок
  открывается обычной ссылкой. Работает при file:// и во вложенном каталоге.
- Связаны переводы нового кейса, переход к следующему проекту и обсуждению похожей задачи.
- Сохранены общий стиль CTA, мобильное меню, анимация, Telegram Share,
  готовая переносимая сборка и корневой запуск для SPCK.
