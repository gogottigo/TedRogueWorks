## Как открыть новый выпуск

Распакуйте TRW_Studio_Patch07_FULL.zip в новую папку, откройте TRW_Studio/index.html в SPCK.
Для просмотра Node.js не нужен. Не накладывайте файлы на старую распакованную версию.
Для оценки мобильной вёрстки сначала выберите разрешение устройства и обычный масштаб.
