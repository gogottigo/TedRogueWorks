# Визуальные исправления Православного мира v1.75

Именно эти изменения применены к локальному проекту перед съёмкой для TRW Studio.
Исходный ZIP пользователя: SHA256 63e27a64961aece9662693bf76c25ea426d76cab9e07a1f5c1697d706be4ee61.

Исправлены: локальная загрузка Inter/Playfair Display без зависимости от Google Fonts;
переносы длинных заголовков; геометрия строки над каталогом и мобильной сортировки;
контраст авторства/лицензии фотографии; переносы действий карточки; ширина первого экрана.
Содержимое каталога, статусы проверки фотографий, ограничения данных и функции сохранены.
Сырой визуал всего проекта полностью не переработан, production-приёмка не заявляется.

Чтобы перенести изменения, распакуйте исходный v1.75 в отдельную папку и запустите:

```sh
python apply.py /полный/путь/к/Pravoslavnii-mir_v1.75
```

Скрипт сначала проверяет исходные HTML по хешам, затем копирует CSS/шрифты, подключает их
к страницам и обновляет файловые контрольные суммы. Не применяется поверх неизвестных
изменённых HTML. Python 3.10+, дополнительные пакеты не нужны. Повторный запуск допустим.
Код для студии не зависит от этого дополнения; для просмотра студии переносить его не нужно.
Лицензии шрифтов находятся рядом с файлами. Playfair Display получен из google/fonts,
ofl/playfairdisplay/PlayfairDisplay[wght].ttf, Inter — из локального пакета студии, SIL OFL.
